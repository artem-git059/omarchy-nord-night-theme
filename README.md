# Nord Night (Omarchy Theme)

A cool theme that combines "nord" and "tokyo night". It blends the deep storm background of Tokyo Night with the frosty arctic accents of Nord.
<img width="1920" height="1080" alt="screenshot-2026-09-30_08-18-08" src="https://github.com/user-attachments/assets/617ec7c4-86d1-46f8-b12b-bd9b67ad4245" />

## 📥 Installation

```bash
git clone https://github.com ~/.config/omarchy/themes/nord-night
omarchy-theme-install https://github.com/artem-git059/omarchy-nord-night-theme
```

## 🎨 Palettes Used
* Background: Tokyo Night Storm (`#1a1b26`)
* Accents: Nord Frost (`#88c0d0`, `#81a1c1`)
